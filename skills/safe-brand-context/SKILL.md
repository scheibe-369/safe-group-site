# Safe brand context

Read the relevant reference before acting:

- Positioning or copy: `references/positioning.md`.
- Visual design or media: `references/visual-system.md`.
- Page, navigation or section work: `references/site-blueprint.md`.

Always write public-facing copy in pt-PT. Never use Unicode U+2014 or U+2013. Never invent proof. Keep Safe positioned for high ticket operations across multiple sectors. Automóvel, financeiro e software/SaaS are experience verticals, not the limits of the offer. Keep AI, marketing, CRM, automation and software framed as tools inside the growth structure, not standalone products.
